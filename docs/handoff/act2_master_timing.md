v7 save generated by the game's `save_write_to`, loaded into libmGBA SRAM before

```sh

cc -std=c11 -O2 -Wno-unused-function -Wno-missing-field-initializers \
  -o build/make-act-start-save tools/playthrough/make_act_start_save.c
build/make-act-start-save build/act2-start.sav
python3 -m unittest tools.tests.test_playthrough_runner
python3 tools/playthrough/run.py --act-start-save build/act2-start.sav tools/playthrough/act2.route
```

(5,8) after the loss. Fixture output belongs under ignored `build/`; do not
pass a real save. The runner accepts a 32768-byte explicit file, but does not
cryptographically attest its provenance: only use the generator's disposable
file. The old single-kin Hall-only route is reproduced by truncating this route
before `party_min 4`, without passing a save (6,154 frames).
