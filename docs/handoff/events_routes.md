To append an event, add stable IDs after existing IDs in `world/events/data.h`, add one of the existing daily slots in `events_new_day_impl`, a Gazette line and a save/act regression test; never reorder the event state prefix or the first ten rematch indices. To add a stop, append to `CARAVAN_ROUTE` and a per-stop NPC, verify it is walkable and reachable with `test_field` (a walkable Maple tile was not necessarily reachable from the route entry), then verify its path against progression gates.
